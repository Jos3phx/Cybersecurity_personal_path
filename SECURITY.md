# Security Policy & Safe Harbor

## 🛡️ Project Purpose
This repository and all scripts, tools, and Proof of Concepts (PoCs) contained within are developed **strictly for educational purposes, academic research, and authorized penetration testing**. 

This is part of a 12-month Cybersecurity Roadmap to understand offensive and defensive security mechanisms. 

## ⚠️ Safe Harbor & Disclaimer
By using any code from this repository, you agree to the following terms:
1. **Authorization:** You will only use these tools on networks, systems, and applications for which you have explicit, written permission from the owner to test.
2. **No Malicious Use:** You will not use these tools for any illegal, malicious, or unauthorized activities.
3. **Liability:** The author (Joey Ramone) assumes no liability and is not responsible for any misuse, damage, or legal consequences caused by the tools or information in this repository.

## 🐛 Reporting a Vulnerability in the Code
While these are educational scripts, if you find a vulnerability in any of the custom tools (e.g., command injection in a parser script) that could affect users running the tool, please practice Responsible Disclosure.

Do not open a public issue. Instead, please report it privately:
* **Email:** [seu-email-aqui@gmail.com]
* Include a brief description of the vulnerability and a proof of concept if possible.

I will make every effort to respond and patch the script as quickly as possible.
